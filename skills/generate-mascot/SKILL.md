# Generate Mascot

This skill generates a new mascot design for a textbook based on a title and description of the textbook. It can also suggest an existing mascot design from the gallery of over 70 samples that matches the textbook's theme. The generated mascot design includes a character name, species, and a set of image prompts for different poses.
