# Mascot Image Prompts: Rune the Raven

Self-contained prompts for generating or regenerating each pose.
Each prompt includes the full base character description — use them independently.

Generate at **1024×1024 pixels**, PNG format, with a **fully transparent background**.
After generating, run `trim-padding-from-image.py` on each file to remove excess padding.

---

A flat cartoon vector illustration of Rune the Raven, a friendly pedagogical mascot

"Ole Cup". Rune has bright, curious amber eyes and a slightly open beak in an encouraging
half-smile. Style: modern flat vector, clean bold lines, transparent background, no text
