## Base Character Description

> Used as the foundation for every pose prompt below. Each prompt is fully self-contained and can be copied independently into any AI image generator.

Tokie is a small, rounded pink cube-shaped character with soft edges and a glossy, slightly sparkly surface. Tokie has large, expressive brown eyes with prominent highlights, a tiny happy mouth, and rosy cheeks. On the top-left of Tokie's head is a small pink flower, and on the top-right is a thin green antenna topped with a glowing green orb. Tokie wears a small pink bow on the front of their body. Tokie has small stubby pink arms and legs. The art style is 3D rendered kawaii/cute, with soft lighting and gentle shadows. The character is compact and icon-sized, suitable for embedding in educational content.

## Image Specifications

- **Format:** PNG with fully transparent background
- **Dimensions:** 512x512 or 1024x1024 pixels (will be displayed at ~90px in admonitions)
- **File size target:** Under 100KB per image for web performance
- **Consistency:** All poses must maintain the same art style, proportions, and color palette

## After Generating Images

1. Save each image with the filename listed above into `docs/img/mascot/`
2. Optionally trim excess padding: `python ../scripts/trim-padding-from-image.py docs/img/mascot/FILENAME.png`
3. Copy `docs/img/tokie.png` to `docs/img/mascot/neutral.png` if using the existing image as the neutral pose
