# Learning Sciences

**Bloom the Elephant** is the mascot for the [Learning Sciences](https://learning-sciences.github.io/dmccreary) textbook. The name doubles as a reference to *Bloom's taxonomy* — the foundational classification of cognitive learning objectives every learning scientist works with — and to the popular saying that "an elephant never forgets," which makes the species a natural symbol for the long-term retention curves the field studies. Bloom was chosen because the mascot encodes two of the discipline's load-bearing ideas (taxonomy of learning, retention over time) in a single character, with no extra explanation required. The choice is strong because the species's cultural association with memory and the name's link to Bloom's taxonomy reinforce each other — a rare two-for-one in mascot design.
