# Image Prompts: Liberty the Bald Eagle

Each prompt below is **fully self-contained** — paste it directly into
ChatGPT/DALL-E, Midjourney, or any AI image generator without needing a
separate base prompt. Generate at 1024×1024 px, PNG format with transparent
background. After downloading, run the trim-padding script (see below).

---

## Base Description (embedded in every prompt)

> A modern flat vector cartoon illustration of Liberty the Bald Eagle,
> a friendly pedagogical mascot for a U.S. History textbook. Liberty has a
> bright white head, rich dark-brown body feathers, and a golden-yellow beak
> and talons. Liberty wears small round amber scholar's glasses and tucks a
> tiny rolled parchment scroll under one wing. Liberty's expression is
> confident, warm, and determined — a slight knowing smile. The character is
> compact and icon-sized. Style: modern flat vector, clean lines,
> transparent background, no text in image.

---

```

A modern flat vector cartoon illustration of Liberty the Bald Eagle,
a friendly pedagogical mascot for a U.S. History textbook. Liberty has a
bright white head, rich dark-brown body feathers, and a golden-yellow beak
and talons. Liberty wears small round amber scholar's glasses. Liberty's
wings are always free — no held objects — so each pose can be fully expressive. Liberty's expression is
confident, warm, and determined — a slight knowing smile. The character is
compact and icon-sized. Style: modern flat vector, clean lines,
transparent background, no text in image.

Liberty stands upright in a relaxed, neutral pose facing the viewer
directly, with a calm and friendly closed-beak smile. Wings rest naturally
at their sides with no specific gesture. The pose is balanced and
unassuming — suitable as a general-purpose or default illustration.

Please generate a new PNG image now with a fully transparent background.
The background MUST be fully transparent. DO NOT use a white, black, or
checkered background.
```
