# Image Prompts: Cress the Tree Frog

Each prompt is fully self-contained — paste any one directly into your AI image
generator (ChatGPT/DALL-E, Midjourney, etc.) without needing a separate base block.

Generate at **1024×1024 px** with a **fully transparent background**, then save
to `docs/img/mascot/` with the filename shown. After saving, run the padding
trimmer so the frog fills the frame:

```bash
python ../../../ibook-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/neutral.png
python ../../../ibook-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/welcome.png
python ../../../ibook-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/thinking.png
```
