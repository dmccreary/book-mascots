# Image Prompts: Scratch the Cat

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

**Character reference:** every prompt below is fully self-contained, but the
canonical description they all derive from lives in
[`character-sheet.md`](character-sheet.md) — if you edit one, update the
other in the same turn.

**Originality note:** these prompts ask for an *original* illustration in
the spirit of the classic Scratch Cat look (orange cat, simple flat-cartoon
style) for use in an independent, non-commercial educational textbook. Do
not ask the image tool to copy, trace, or reproduce MIT/Scratch Team's actual
sprite artwork or logo — describe the character fresh, as written below.

Recommended generation size: 1024×1024, then resize down for use. After
saving each image, run the padding trimmer (commands at the bottom of this
file).

## Base Character Description

Please generate a new pose for Scratch the Cat.

A flat 2D cartoon/vector illustration of Scratch the Cat, a friendly
pedagogical mascot for a Scratch visual block-based programming textbook for
kids ages 8-12. Scratch is a warm tangerine-orange cat (hex #FF8C1A) with a
cream/light-peach belly, inner ears, muzzle, and paws (hex #FFE0B2). Scratch
wears no clothing or accessories — just clean fur and a simple, friendly
face. Scratch has big round curious eyes with dark pupils, small triangular
ears, soft whisker lines, and stands upright on two legs in chibi-style
proportions with a slightly oversized head relative to the body. Style: flat
vector illustration, bold clean black outlines, bright saturated flat colors,
no gradients or textures, transparent background with alpha channel,
suitable for embedding in educational content. No text in image.

Please generate a new RGBA PNG image now with a fully transparent
alpha-channel background. The background MUST be fully transparent with an
alpha channel. DO NOT use a white, black, or checkered background.

trim excess transparent padding so the mascot doesn't appear too small in
the 90px admonition slot. Run this from the project root:

```bash
for f in neutral welcome thinking tip warning encouraging celebration; do
  python3 /Users/dan/.claude/skills/book-installer/scripts/trim-padding-from-image.py "docs/img/mascot/$f.png"
done
```
