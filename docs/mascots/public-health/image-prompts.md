# Image Prompts: Sage the Crane

Self-contained AI image-generation prompts for every pose of **Sage the
Crane**, the pedagogical mascot for **Introduction to Public Health**.

Each prompt below is **fully self-contained** — copy a single prompt into
your AI image generator (ChatGPT/DALL-E, Midjourney, Stable Diffusion,
Gemini, etc.) and you will get one consistent pose. Do not edit the base
description across prompts unless you also update
[`character-sheet.md`](character-sheet.md).

**Output specs to request:**

- PNG with a fully transparent background
- 1024 × 1024 px (downscale later for web)
- No text in the image
- Single character, centered, full body visible

After generating, save each file in `docs/img/mascot/` using the filename
listed below the prompt, then run the padding-trim script (see end of
this file).

---

## 1. Neutral / Default Pose — `neutral.png`

```
Please generate a new pose for Sage the Crane.

A modern flat cartoon vector illustration of Sage the Crane, a friendly
pedagogical mascot for a Public Health textbook. Sage is a slender white
crane with light gray feather shading, a small teal scarf around the
neck, round wire-frame glasses at the base of the beak, and a clipboard
tucked under one wing. The beak and legs are deep orange. Sage has
calm, attentive eyes and a closed-mouth friendly expression. The
character is small and compact, suitable for icon-sized display at 90px.
Style: modern flat vector, clean lines, solid fills, subtle shading,
transparent background, suitable for embedding in educational content.
No text in image.

Sage stands upright in a relaxed, neutral pose facing the viewer
directly, with a calm and friendly closed-mouth smile. The wings rest
naturally at the sides with no specific gesture. The pose is balanced
and unassuming — suitable as a general-purpose or default illustration.

Filename: neutral.png

Please generate a new png image now with a fully transparent background.
The background MUST be fully transparent. DO NOT use a white, black, or
checkered background.
```

## After Generating: Trim Excess Padding

AI generators almost always add invisible transparent padding around the
character. Untrimmed, the mascot appears tiny inside the 90px admonition
box. Run this script on every pose:

```bash
python ~/Documents/ws/claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/neutral.png
python ~/Documents/ws/claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/welcome.png
python ~/Documents/ws/claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/thinking.png
python ~/Documents/ws/claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/tip.png
python ~/Documents/ws/claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/warning.png
python ~/Documents/ws/claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/encouraging.png
python ~/Documents/ws/claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/celebration.png
```

The script trims transparent padding to the bounding box of the visible
content and overwrites each file in place.

After trimming, run `mkdocs serve` and open
`http://127.0.0.1:8000/public-health/learning-graph/mascot-test/` to
verify all seven poses render correctly inside their admonitions.
