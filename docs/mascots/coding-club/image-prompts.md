# Image Prompts: Circuit the Robot

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

## Base Character Description

Use this description at the start of every pose prompt below — each prompt
is fully self-contained so it can be used independently.

```
A flat cartoon/vector illustration of Circuit the Robot, a friendly
pedagogical mascot for a coding club textbook covering coding club
operations, mentorship, physical computing, and AI-assisted club
management. Circuit is sky blue (#4A90D9) with warm amber (#F5A623)
accents, with a small antenna topped with a glowing amber LED bulb and a
rounded chassis with a soft digital screen face. Circuit has a friendly,
warm screen-face with a simple curved smile display. The character is
small and compact, rounded proportions, approachable rather than imposing
-- like a friendly desktop helper robot. Style: flat cartoon/vector
illustration, clean lines, bold simple shapes, transparent background with
alpha channel, suitable for embedding in educational content. No text in
image.
```
