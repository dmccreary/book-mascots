    AI Image Generation Prompts for Ferris the Fox¶

    Character Summary¶

    • Name: Ferris the Fox
    • Species: Fox
    • Colors: Orange fur, cream chest, green vest, yellow bow tie
    • Accessories: Green vest + yellow bow tie only — no glasses, no backpack, no props
    • Hands: Always free for gesturing
    • Personality: Clever, encouraging, curious, slightly playful
    • Catchphrase: "Think like an economist!"
    • Art style: Modern flat vector cartoon, clean lines, transparent background

    Important Requirements for ALL Images¶

    • Images MUST be PNG format with a transparent background
    • Use very small padding around the drawing — the character should fill most of the canvas
    • Generate at 1024x1024 pixels, then resize down for web use
    • Excessive padding will make the mascot appear too small when displayed at the target CSS size
